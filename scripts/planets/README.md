# Halftone-планеты

Генератор зацикленных GIF: восемь планет Солнечной системы в той же
точечной графике, что и кадры на zorahm.com.

```bash
node scripts/planets/render-gifs.mjs                # все восемь → gifs/
node scripts/planets/render-gifs.mjs mars jupiter   # выборочно
node scripts/planets/preview.mjs                    # контактный лист gifs/preview.png
node scripts/planets/check-loop.mjs                 # проверка бесшовности петли
```

Ключи `render-gifs.mjs`: `--size=480` `--step=7` `--fps=20` `--seconds=5`
`--jitter=1` `--out=gifs`. `--jitter=0` убирает дрожание точек и снимает с
файла около 40% веса.

## Как это работает

Пайплайн повторяет сайт: сетка узлов → функция `field(x, y, t)` возвращает
яркость 0..1 → узел рисуется точкой радиусом `maxRadius · v^0.8`, самые
яркие узлы достаются золоту. Разница в том, что на сайте поле считает GPU
при бесконечном времени, а здесь — CPU при фазе петли `t ∈ [0, 1)`.

Отсюда главное правило: **всё движение обязано быть периодичным по t.**
Спутник делает целое число оборотов за петлю, дрожание берёт фазу `2π·t`,
шум индексируется шагом с остатком по модулю. Нарушение ловит
`check-loop.mjs` — он сравнивает кадр при `t = 1` с кадром при `t = 0`.

| Файл | Что делает |
| --- | --- |
| `core/geometry.mjs` | сетка и опорный масштаб: `1.0 · scale` — край кадра |
| `core/math.mjs` | хелперы поля, проекция шара, свет, контраст |
| `core/textures.mjs` | запечённый холст (как на сайте) и карта в координатах долгота/широта |
| `core/maps.mjs` | кисти для карт: пятна, пояса, кратеры, материки |
| `core/render.mjs` | отрисовка кадра и сборка GIF дельта-кадрами |
| `planets/*.mjs` | по модулю на планету: `{ id, title, accent, create(geom) }` |

Планета возвращает из `create(geom)` объект с `field(nodeX, nodeY, t)`.
Координаты узлов — как на сайте: X вправо, **Y вверх**.

## Чем планеты отличаются

Сатурн перенесён из `src/components/field/shapes/saturn.ts` построчно,
включая запекание колец и поясов; квантованы только скорости обломков.
Остальные семь написаны с нуля.

Поверхность вращается не сдвигом плоской картинки: точка диска переводится
ортографической проекцией в долготу и широту, и уже по ним берётся карта —
поэтому детали уходят за лимб со сжатием. У Юпитера и Нептуна долгота
сдвигается по-разному в зависимости от широты, так что пояса разъезжаются
друг относительно друга.

| Планета | Что показывает |
| --- | --- |
| Меркурий | жёсткий терминатор, кратеры, равнина Жары |
| Венера | ретроградная суперротация облаков, деталь Y, свечение лимба |
| Земля | материки и облака вращаются с разной скоростью, Луна на орбите |
| Марс | Большой Сирт и Долины Маринер, шапки, пылевая дымка, Фобос и Деймос |
| Юпитер | пояса с дифференциальным вращением, Красное пятно, резонанс 8:4:2 |
| Сатурн | кадр с сайта: кольца, обломки, спутники |
| Уран | кольца стоймя, два слоя запекания ради перекрытия диском |
| Нептун | встречные струи, Большое тёмное пятно, ретроградный Тритон |
